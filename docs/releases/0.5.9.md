# AgentWiki Sync 0.5.9

修复多空间同步与附件引用解析问题：

- 某个映射的本地目录缺失时，同步中心仍显示空间选择，可切换到其他空间继续首次拉取。
- 同步目标状态避开 Obsidian 1.14.4 的宿主字段覆盖，打开窗口后能正确选择并同步目标空间。
- 文档代码示例中的 HTML 注释标记不再误吞正文图片引用，避免远端拉取报 `ATTACHMENT_REFERENCES_INVALID`。真实注释、行内代码和嵌套代码块中的示例图片仍按上下文排除。

保留显式预览与确认流程、原有映射和正文。最低 Obsidian 版本仍为 1.11.5；安装文件为 `main.js`、`manifest.json`、`styles.css`。本补丁无需更新 AgentWiki 服务端。

修复已通过独立代码复审，以及 macOS Obsidian 1.14.4 原仓库的首次拉取与再次同步检查。
