# AgentWiki Sync 0.5.12

本版本改善附件超限与推送恢复失败时的说明和诊断。

- 附件超限会区分附件大小、数量、分块、图片边长、解码像素和总传输量，并显示实际数值、上限及可确认的路径，提供压缩、缩图或减量建议。服务端只提供错误码时会明确说明缺少具体对象与数值。
- 推送恢复失败会显示经过校验的事务、会话、已知远端状态和本地阶段。远端已发布但本地未完成、远端状态未确认分别说明；损坏的日志不会作为可信证据显示。
- 同步中心提供“重试恢复”“导出诊断”和“关闭”。诊断文件仅导出白名单标识与状态，不包含凭据、页面正文、附件、请求内容或原始事务日志。
- 普通加载错误与 Pull 阶段失败不再借用旧 Push 事务说明；首次 Push 日志读取或完整性校验失败也会显示保留记录和安全恢复指引。

保留现有协议、附件硬上限、身份与哈希校验、同步预览和确认规则；没有新增清除事务或自动重新推送动作。恢复问题仍应保留 Vault 与完整 `.agentwiki` 控制目录的备份，再由管理员核对服务器会话和发布记录。

本版本已完成隔离回归与 macOS 临时 Vault 的诊断界面验收；原反馈 Windows Vault 的附件超限和恢复失败场景仍待原环境重放，不能据此认定业务同步已完成。
