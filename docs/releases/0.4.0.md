## 0.4.0 — Markdown 引用图片同步

### 验收状态与使用提醒

最终候选已完成真实 macOS 桌面与 Android 验收，并通过公网六项恢复测试，包括 create/finalize 成功响应丢失后的恢复。测试范围为获授权的合成测试 Space 和映射，不将其表述为所有设备、格式及用户数据组合的穷尽测试。

建议先备份 Vault，在独立测试映射中验证后再用于重要笔记。遇到无法确定归属的异常移动回滚，插件会保留文件与基线并停止同步，需要人工处理，不会自动覆盖或删除可能包含新编辑的内容。

### 本次变化

- 通过 Sync v3 同步 Markdown 实际引用的 PNG、JPEG、WebP、GIF；不批量扫描上传未引用附件。
- 支持首次本地图片升级、远端图片下载、短链接规范化、稳定附件身份及明确的冲突预览。
- 改进中断恢复与本地修正事务，保留固定版本、确认边界及异常证据。
- 修复 inline-code 边界与重复反引号扫描性能，保留转义和精确引用范围语义。
- 配套 AgentWiki 服务端解析器修正已经备份、部署并通过部署产物检查与公网健康检查。

### 已完成的验证

- 插件完整检查：66 个测试文件、1,313 项测试通过；构建、类型与产物检查通过；17 条既有 lint warning，0 error。
- npm 依赖审计：0 漏洞。
- 配套服务端完整测试：148 组、2,570 项通过；1 项 Windows 专用测试在 macOS 上跳过。
- 独立代码审查及修正复审通过；跨解析器样例与稳定引用 ID 检查通过。

- 同一最终包在桌面与 Android 分别完成全新 Legacy Space 首张引用图片升级；真实预览确认、固定版本下载、基线终结和重复同步零写入均通过。
- 双端同版本缺失图片恢复、中文/空格/子目录重命名及稳定附件身份通过；桌面取消引用保留图片文件，再引用复用原附件 ID。
- 双端完整 Obsidian 进程离线重启通过：离线仍可显示本地图片，同步明确报网络错误且不改写数据，恢复网络后同步无变更。
- 公网原版六项恢复测试 6/6 通过；未引用图片不读取、不上传，既有其他映射保持不变。

详见仓库中的 `docs/verification/2026-09-08-final-native-release-gates.md` 及其关联报告。GitHub Release 与实际发布资产安装校验是发布阶段的独立检查；GitHub Release 不等于 Obsidian 社区目录已完成审核。

### 安装

下载本 Release 的 `main.js`、`manifest.json`、`styles.css`，放入 Vault 的 `.obsidian/plugins/agentwiki-sync/`，保留既有 `data.json` 和其他配置，然后重新加载插件。最低 Obsidian 版本为 1.11.5。
