# AgentWiki Sync 0.5.11

本版本修复空间映射移除和重建期间的本地状态问题。

- 移除映射后，旧基线和同步控制数据完整归档，重新添加同一空间到其他目录时不再误用旧目录基线。本地 Markdown 保留。
- 差异刷新、移除映射和断开连接互斥；已排队的重命名记录写完后再清理同步运行时，避免后台写入重新创建旧控制目录。
- 设置并发保存保留映射状态；中断的移除可根据持久设置恢复，未完成的同步事务继续阻止移除。
- 基线目录、空间身份和清单哈希不匹配分别显示原因，未放宽完整性校验。

包含 0.5.10 的全部目录归档和旧任务恢复修复。同步预览与确认规则不变。

Windows 复测中服务端 `head` 返回 410 的问题由 AgentWiki 服务端修复，本插件不会通过删除或重写基线绕过该错误。
