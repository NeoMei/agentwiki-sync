# AgentWiki Sync 0.5.7

本次补丁修复本地删除父目录、远端同时新增后代时的目录合并边界。

- 同步预览保留远端父目录信息，并展示可处理的目录冲突。
- 选择保留目录时，会补建本地缺失目录；填写新路径可移动目录及其后代。
- 目录仍有后代时阻止直接删除，提供中英文处理指引，继续保留显式预览与确认。

验证范围：

- 发布候选运行完整格式、lint、类型、自动化测试、生产构建、bundle 安全与版本一致性检查。
- 本轮 macOS 隔离 Vault 已验证 Sync v2 首次同步及自动创建三级映射目录；原生验收对应功能候选 `e5b8a3a`，后续仅补充中英文错误提示和发布元数据。
- 原测试者的 `UNKNOWN_PARENT` 现场、Windows 原生环境与本轮 Sync v3 原生场景仍待验；本次发布不代表这些环境已全部闭环。
