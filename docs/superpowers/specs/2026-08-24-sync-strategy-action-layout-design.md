# 同步策略操作区布局设计

## 目标

修复桌面端，尤其 Windows Obsidian 中同步策略说明被三个长按钮挤压成窄列的问题，同时保持移动端可用性。

## 已确认方案

- 同步策略说明不再作为 `Setting.setDesc()` 的左栏内容，而是在操作区上方使用独立段落展示。
- 三个同步策略按钮放在下一行，默认从左到右排列并允许换行。
- 响应式判断基于同步弹窗容器宽度，不依赖 `.is-mobile` 或 `.is-phone` 平台类。
- 窄容器下三个按钮纵向排列并占满可用宽度。
- “自动合并（推荐）”继续保持主按钮，其他两个策略保持次要按钮。

## 边界

- 不改变同步策略、权限判断、点击行为或文案。
- 不调整设置页及其他弹窗。
- 不新增运行时依赖。

## 验证

- 增加源码与样式契约测试，防止说明重新进入 `Setting` 左栏或响应式规则退回平台判断。
- 运行插件完整 `npm run check`。
- 使用 560px 默认弹窗和窄容器进行渲染检查，确认说明保持正常段落宽度、按钮不挤压文字。
